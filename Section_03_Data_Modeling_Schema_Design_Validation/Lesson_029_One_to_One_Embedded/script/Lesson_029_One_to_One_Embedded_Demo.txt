MongoDB mongosh demo — One-to-One — Embedded

Prerequisite
------------
Run from a machine where mongosh can connect to MongoDB.

1) Start a clean demo database
-------------------------------
use orderdb_one_to_one
db.dropDatabase()

2) Create one order with one embedded shipping address
-------------------------------------------------------
db.orders.insertOne({
  orderId: "ORD-1001",
  orderDate: ISODate("2026-09-15T10:30:00Z"),
  status: "CONFIRMED",
  totalAmount: 1024.50,
  shippingAddress: {
    street: "12 MG Road",
    city: "Chennai",
    state: "Tamil Nadu",
    country: "India",
    pinCode: "600001"
  }
})

3) Read the complete parent document
------------------------------------
db.orders.findOne({
  orderId: "ORD-1001"
})

4) Read the embedded one-to-one field
--------------------------------------
db.orders.findOne(
  { orderId: "ORD-1001" },
  { _id: 0, orderId: 1, shippingAddress: 1 }
)

5) Read one nested field
------------------------
db.orders.findOne(
  { orderId: "ORD-1001" },
  { _id: 0, orderId: 1, "shippingAddress.city": 1 }
)

6) Verify the address is contained in the same document
--------------------------------------------------------
db.orders.countDocuments({
  orderId: "ORD-1001"
})

// Expect: 1

7) Design observation
---------------------
print("One order contains one shippingAddress object.")
print("The child is small, bounded, owned, and read with the parent.")
print("The application can retrieve parent + child in one document read.")

8) Optional cleanup
-------------------
db.dropDatabase()
