MongoDB hands-on demo — Understanding Relations

Purpose
-------
See how one-to-one, one-to-many, and many-to-many relationships can be represented in an Order Management model.

Prerequisite
------------
Run from a machine where mongosh can connect to MongoDB.

1) Start mongosh
----------------
$ mongosh

2) Use a clean demo database
----------------------------
> use orderdb_relations_demo
> db.dropDatabase()

3) Insert a customer with an embedded shipping address (1:1)
--------------------------------------------------------------
> db.customers.insertOne({
    customerId: "CUST-1001",
    name: "Acme Corp",
    email: "contact@acme.com",
    shippingAddress: {
        city: "Mumbai",
        country: "India"
    }
})

4) Insert products (shared catalog side of N:M)
-------------------------------------------------
> db.products.insertMany([
    { productId: "P100", name: "Laptop", category: "Electronics" },
    { productId: "P200", name: "Mouse", category: "Accessories" },
    { productId: "P300", name: "Keyboard", category: "Accessories" }
])

5) Insert orders that reference the customer and product ids
-------------------------------------------------------------
> db.orders.insertMany([
    {
        orderId: "ORD-1001",
        customerId: "CUST-1001",
        status: "CONFIRMED",
        items: [
            { productId: "P100", quantity: 1 },
            { productId: "P200", quantity: 2 }
        ]
    },
    {
        orderId: "ORD-1002",
        customerId: "CUST-1001",
        status: "SHIPPED",
        items: [
            { productId: "P100", quantity: 1 },
            { productId: "P300", quantity: 1 }
        ]
    }
])

6) Inspect the parent document and its embedded 1:1 relation
--------------------------------------------------------------
> db.customers.findOne({ customerId: "CUST-1001" })

7) Find all orders for the customer (1:N reference)
-----------------------------------------------------
> db.orders.find({ customerId: "CUST-1001" }).pretty()

8) Find orders that contain a specific product id (N:M)
--------------------------------------------------------
> db.orders.find({ "items.productId": "P100" }).pretty()

9) Inspect only the embedded address
--------------------------------------
> db.customers.findOne(
    { customerId: "CUST-1001" },
    { _id: 0, customerId: 1, shippingAddress: 1 }
)

10) Relationship map to observe
-------------------------------
Customer 1:1 Address      -> address is embedded
Customer 1:N Orders       -> orders are separate and use customerId
Orders   N:M Products     -> order items carry productId references

11) Practice
------------
Create a second customer and give that customer two orders. Then insert a fourth product and add its productId to one order's items array.

What to observe
---------------
• Cardinality describes how many records participate in the relation.
• Embedded data stays inside the parent document.
• Referenced data lives separately and is connected through identifiers.
• Access patterns and growth help determine which representation is appropriate.

Cleanup (optional)
------------------
> db.dropDatabase()
